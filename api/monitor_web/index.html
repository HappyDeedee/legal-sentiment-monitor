任务监控

舆情监控

配置律所舆情任务，把平台采集、过滤去重、AI 评估和报告发送串联起来。

采集规则说明
当前首版以平台搜索词采集为主。平台搜索词会用于平台搜索；律所名称、别名和排除词用于评估、报告和采集后过滤。

新建任务

任务配置负责串联调度、平台采集、AI 评估和邮件发送；账号、代理、AI 接入、邮件模板在各自资源页独立维护。
普通用户只需填写目标律所、平台搜索词、采集范围、调度和收件邮箱。账号、代理、AI 接入、邮件模板和浏览器方式由管理员维护。
1. 目标填写律所名称和别名，用于报告归属和线索判断。
2. 采集内容选择平台、输入平台搜索词，并设置采集范围。
3. 调度选择运行频率、发送时间和是否启用任务。
4. 报告填写日报收件邮箱；未填写时仍可生成报告。

1. 目标

律所名称和别名用于 AI 判断、报告标题和线索归属，不会自动追加为平台搜索词。

2. 采集内容

平台搜索词会逐行传入平台搜索。律所名称和别名只用于评估、报告和线索归属。

这里的每一行才会用于平台搜索；律所别名不会自动参与搜索。
采集条数是内容数量上限；起始页和页数会按平台能力执行，部分平台可能返回少于所选范围的结果。任务运行超时由管理员在运行策略中统一控制。

过滤与去重

排除词不参与平台搜索，只在内容采回后过滤标题、正文、作者和来源搜索词。系统最终按发布时间和内容 ID 去重。

管理员高级采集设置

仅管理员可绑定账号、代理和采集技术参数；普通用户任务会使用系统自动选择的资源。

采集参数
当前任务按平台搜索词运行。平台搜索词、平台和采集范围会共同决定本次采集内容。

3. 调度

设置任务是否启用、多久运行一次，以及每次只处理哪个时间范围内的新内容。

AI 评估

选择用于本任务的 AI 接入资源。未选择或接入异常时，采集仍会运行，内容进入待人工复核。

4. 报告

设置报告收件人和本任务使用的邮件模板。任务收件人优先；留空才使用邮件配置里的全局默认收件人。发件人只代表 SMTP 身份，不会自动成为收件人。

未填写任务收件人时，系统会尝试使用全局默认收件人；两者都为空时只生成报告，不发送邮件。未配置邮件也可以采集和生成报告，只是不发送邮件。
